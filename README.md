# Study Lab

Appunti rielaborati, esercizi e strumenti personali di studio. Progetto personale, non un sito ufficiale H-FARM. I documenti originali dei docenti non sono distribuiti. Le fonti e i limiti didattici sono indicati nelle pagine.

Sito statico su GitHub Pages; nessun account richiesto per consultarlo. Gli esercizi non sincronizzano i progressi tra dispositivi.

Questo repository contiene la sola esportazione pubblica approvata. La fonte privata viene mantenuta separatamente. Aggiornare tramite esportazione filtrata, mai caricando la cronologia o l’intero workspace privato.
